# How to Use

1. Paste a link into the URL box and select **Analyze** or press Enter.
   - A single video opens the options panel.
   - A playlist opens a checklist. Select videos for batch download or click one track to inspect its options.
2. Choose **Video** or **Audio**.
   - Video: select MP4/MKV/WEBM and a quality such as `1080p`.
   - Audio: select a format such as MP3 or FLAC and an available bitrate.
3. Configure optional settings:
   - Subtitles: author-uploaded or auto-generated tracks, languages, SRT/VTT, embed or separate file.
   - Filename prefix: date/time, channel and title.
   - Thumbnail: embed, save alongside, or skip.
   - Save location: defaults to `%USERPROFILE%\\Downloads` and can be changed with **Choose Folder**.
4. Select **Download Now**. The progress bar and live log show the current operation.
5. Use the Windows toast after completion to open the save folder. Download history remains available below the main panel, with actions to play, copy the path, open the folder or delete an entry.
